# Проверки

Для прототипа запускай `npm run build` и проверяй [локальный сервер](http://127.0.0.1:5188/) в браузере на мобильной и широкой ширине. Для документации проверяй локальные ссылки, полноту маршрутов и актуальность журнала задач.

Первые сценарии для проверки приложения:

- создание аккаунта, верная и неверная активация по суточному коду, разделение данных учеников;
- создание задачи ментором и разрешённый и запрещённый перенос менти;
- круг на главной, свайп, кнопки, три слоя при наклоне и подписи секторов;
- профиль, слои и фотодневник до и после перезагрузки;
- все 30 вопросов, однократность прохождения, результат и отдельная правка оценки ментором;
- одинаковый список софтов и отдельный прогресс у двух менти, круг хардов из двух навыков и Lottie на пороге;
- доступные события подключённого проекта и состояние при недоступной интеграции.

В отчёте фиксируй команду или способ проверки, результат и пробелы. Для ручных проверок используй [MANUAL-CHECKS.md](MANUAL-CHECKS.md).
