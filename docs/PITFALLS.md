# Грабли

Сюда записываем подтверждённые сбои Edinstvo-Learn, на диагностику которых ушло время. Для каждого укажи симптом, причину, как проверить исправление и где оно находится.

- **Обработчик ссылается на переменную из другого метода.** Симптом: клик по задаче проекта ничего не делает, в консоли `ReferenceError: project is not defined`. Причина: шаблон задач перенесли из окна проекта в общий метод, а переменная осталась в старом месте. Сборка Vite такое не ловит. Проверка: после переноса разметки пройти сценарий в браузере и убедиться, что в консоли нет ошибок. Исправление в `projectWeeks` в [src/app.js](../src/app.js).
- **Сравнение только времени без даты.** Симптом: в «Ближайшем» висит вчерашняя задача на 23:00. Причина: условие сравнивало время задачи с текущим, не проверяя, что задача сегодняшняя. Проверка: тест `upcomingTask skips done and past tasks`. Исправление в [src/schedule.js](../src/schedule.js).
- **Голосовой ввод и Т9 меняют смысл.** Симптом: «подлиннее» пришло как «подлинные», и вместо удлинения анимаций их заменили. Если слово в просьбе Макара меняет объём работы или удаляет сделанное, сначала коротко уточни.
