# Интерфейс

- Белый фон на всех экранах. Обводки допустимы на круге навыков, фокус клавиатуры сохраняем. Цвет используется в иллюстрациях, навыках и состояниях.
- Martian Grotesk для основного текста, Martian Mono для чисел и дат. Сначала проектируем узкий экран Telegram, на ПК расширяем композицию.
- Стеклянные поверхности делаем на Edinstvo Glass. На круге используем прозрачный CSS-материал, а параллакс двигает три слоя раздельно.
- Сверяй вёрстку с актуальным кадром Figma целиком. Точные размеры, отступы и токены бери из свойств узлов.
- В пользовательском тексте избегай длинного тире и разделителя «·». Для длинных названий предусмотрено чтение полного текста, способ выбирай по макету и контексту. Тени берём из макета.
- Проверяй состояния загрузки, пустого списка и ошибки. В профиле и календаре показывай реальные данные и доступные действия.
- Проверяй в Telegram Mini App на узком экране. Для GSAP учитывай системную настройку уменьшенного движения.
