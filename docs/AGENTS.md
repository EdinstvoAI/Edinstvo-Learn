# Работа агентами

Запускай агентов только по просьбе Макара и только в пределах указанной задачи. Прерванного агента сначала возобнови с его текущей точки.

## Запуск

- Для правок кода выдели каждому агенту собственный worktree и ветку. Заранее разнеси файлы, тестовые данные и порты. Проверяющий агент работает на чтение, временные файлы держит вне репозитория.
- В задании укажи результат, границы файлов, [CLAUDE.md](../CLAUDE.md), документ области, способ проверки и формат отчёта. Общие сервисы и чужие тестовые данные требуют координации.
- Пуш, слияние, релиз и изменения внешних сервисов выполняются по указанию Макара.

## Отчёт и приём

- Для находки укажи шаги, ожидание, результат и подтверждение. Для исправления укажи затронутые файлы или коммит, проверки, оставшиеся пробелы и убранные временные данные.
- Основная сессия сверяет находки с кодом, проверяет изменения в основном сценарии и записывает статус в [TASKS.md](TASKS.md).
- Если работа оборвалась, найди её по журналу и выводу `git worktree list`. Слияние проводят по [GIT.md](GIT.md).
