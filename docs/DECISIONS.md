# Решения

## 2026-11-11

- Две роли: ментор (Макар) и менти. Вход через Telegram Mini App.
- Направления продукта: трекинг проектов, навыки и прогресс в профиле менти, календарь задач. Возможность переноса задач менти управляется ментором.
- Для проекта нужна привязка GitHub и Figma по ссылкам с отслеживанием изменений.
- Lit и GSAP — исходный выбор для фронтенда и анимаций. PostgreSQL и Docker — предварительный выбор для хранения данных и запуска. Стек бэкенда открыт.
- Система работы с агентами основана на соседнем репозитории «Единство». Общий вход через `CLAUDE.md`, для Codex вход через `AGENTS.md`.
- Макар уже ведёт нескольких менти. Профиль показывает прогресс конкретного менти, у ментора есть несколько таких профилей.
- Для визуализации навыков используем круговую диаграмму с секторами и анимированным ростом по ролику «10 слайд.mp4». Макар отдельно даст дизайн-референс. Наблюдения по ролику в [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md#навыки).
- Зелёный круг софтов содержит одинаковый список из десяти навыков для всех менти. Фиолетовые круги хардов Макар собирает под каждого менти и может добавлять дополнительные. Анимации у обоих типов в стиле Telegram, эффекты на Lottie. Список навыков записан в [PRODUCT.md](../PRODUCT.md#навыки).
- У каждого свой аккаунт через Telegram. Менти проходит входной тест один раз. Результат приблизительный, хранится отдельно от последующих оценок Макара.
- Харды стартуют с нуля. Круг содержит до 10 навыков, ментор выставляет уровни. При достижении хорошего уровня во всём круге проигрывается Lottie. В прототипе порог 75%.
- Белые экраны, Martian Grotesk и Martian Mono, Edinstvo Glass, три слоя с параллаксом. На главной круги и отдельный блок проектов. Профиль отдельный, с настройкой слоёв и фотодневником.
- Счётчики проектов, коммитов и Figma из профиля убраны. Случайные баттлы не входят в приложение. Покер на очки остаётся открытым вопросом.

Открытые вопросы, включая механику навыков и покер без денег, ведём в [PRODUCT.md](../PRODUCT.md).

## 2026-11-12

- Разработка в `dev`. У `main` пока нет коммитов. Фронтенд и API в одном Docker-контейнере, PostgreSQL в отдельном сервисе с томом.
- Администратор начинает со списка учеников. Вход ученика создаёт аккаунт автоматически, а для первого доступа нужен текущий код из кабинета. Код обновляется в полночь по Волгограду.
- Экран ученика собираем по композиции Helper целиком. Фирменный логотип, переключатель кругов и содержание проекта берём из референсов Макара.

- 2026-11-12. На компьютере менти видит тот же узкий интерфейс Mini App. Сводка находится на «Скиллах». Календарь показывает ближайшую задачу, проект собирает связанные задачи, профиль использует фото из Telegram при наличии. Это повторяет композицию Макара и сохраняет единый сценарий на обоих устройствах.

- 2026-11-12. Экран «Скиллы» заканчивается диаграммой. Подписи всегда видны. Планы и проекты открываются через док. Верхний отступ уменьшен под Mini App. В проектах менти выбирает одну из 15 фактур папки.

- 2026-11-12. Скрытый вход ментора: удержание логотипа 10 секунд → почта и пароль → PIN. Данные лежат в окружении как хеши, отдельной таблицы нет: ментор один, а так не появляется сценарий регистрации и сброса пароля. Макар одобрил слияние ветки с исправлениями и тестами в `dev`.

- 2026-11-12. Lottie-сцены теста делаем в стилистике существующих анимаций и из их объектов, без отдельного макета. Паузы теста после 9, 20 и 25 ответов. Радар остаётся как есть.
- 2026-11-12. Анимации теста делаем по видеореференсу Макара: крупные глянцевые кубики на прозрачном фоне, сами объекты служат маской. Ментор правит навыки в процентах прямо в списке, софт и хард одинаково, обоснование необязательно. В календаре «все» показывает задачи выбранного дня, «новые» — созданные за неделю. Роль на карточке профиля задаёт ментор. В локальном запуске первая страница — вход по имени и коду.
