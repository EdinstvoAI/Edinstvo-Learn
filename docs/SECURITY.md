# Доступ и секреты

- Роль и доступ к данным менти проверяет сервер. При изменении прав проверяй обе роли и запрос к чужому профилю, проекту и задаче.
- Секреты Telegram, GitHub, Figma и БД передаются серверу через окружение. В репозитории можно хранить имена переменных и примеры с фиктивными значениями.
- Для интеграций запрашивай доступ только к ресурсам, которые нужны для отслеживания. Учитывай приватность проектов и показывай активность только тем, у кого есть право её видеть.
- Храни минимум персональных данных. Убирай токены и личные данные из отчётов и снимков.
