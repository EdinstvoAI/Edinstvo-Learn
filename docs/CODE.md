# Правила кода

- Имена переменных, функций, полей, классов и анимаций пиши по-английски. Комментарии можно писать по-русски. Объясняй причину решения и неочевидные ограничения.
- Используй существующие компоненты и модули. Выноси общую логику, когда ей действительно пользуются несколько сценариев.
- Проверяй доступ и возможность изменения на сервере. Отключённая кнопка в интерфейсе дополняет серверную проверку.
- Продумай пустое состояние, ошибку и запоздалый ответ. Данные в интерфейсе должны соответствовать открытому проекту или профилю.
- Новую структуру отмечай в [MAP.md](MAP.md), изменение поведения и прав — в [ARCHITECTURE.md](ARCHITECTURE.md).
