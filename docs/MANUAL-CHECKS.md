# Ручная проверка

Список для Макара заполняется перед показом работающего сценария. Для каждого пункта укажи роль, устройство или экран, короткие шаги и ожидаемый результат. Оставляй здесь сценарии, где действительно нужна оценка Макара, например удобство календаря на телефоне и ощущение анимации в Telegram.

Когда прототип будет доступен по HTTPS в Telegram, открыть главную на телефоне, разрешить наклон при запросе, слегка повернуть устройство. Подложка, секторы и блик двигаются на разную глубину. Горизонтальным свайпом проверить смену круга и читаемость подписей.
