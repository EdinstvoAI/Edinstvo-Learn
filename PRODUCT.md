# Edinstvo-Learn

Telegram Mini App для менторства. Макар уже ведёт нескольких менти. В приложении он ставит задачи и видит, как продвигается работа каждого. Менти видит свои задачи и прогресс.

## Что хотим сделать

- **Вход через Telegram.** Первый запуск создаёт отдельный аккаунт ученика. Первый доступ открывает шестизначный код из кабинета Макара. Код меняется в полночь по Волгограду.
- **Кабинет администратора.** У Макара отдельный стартовый экран со списком учеников. Из карточки ученика доступны навыки, задачи, проекты и фотодневник.
- **Проекты.** Привязать к проекту ссылки на GitHub и Figma и видеть изменения по ним.
- **Главная.** Сразу показывает перелистываемые круги навыков. Проекты идут отдельным блоком ниже.
- **Профиль менти.** Отдельный экран с настраиваемой обложкой и слоями. Менти добавляет фотографии рабочего процесса с подписями и видит их в хронологической ленте.
- **Календарь.** Ментор ставит задачи и управляет тем, может ли менти их переносить.
- **Навыки.** В профиле менти два основных круга с секторами навыков. Зелёный показывает софты, фиолетовый — харды. Ментор может добавить дополнительные круги хардов. Оба типа используют Lottie-анимации в стиле Telegram по [видеореференсу](docs/DESIGN-SYSTEM.md#навыки).

## Навыки

**Софты.** Список одинаковый для всех менти, прогресс у каждого свой.

1. Критическое мышление.
2. Аналитическое мышление.
3. Коммуникация.
4. Командная работа.
5. Самостоятельность.
6. Адаптивность (реакция на изменения).
7. Рефлексия.
8. Инициативность.
9. Работа с обратной связью.
10. Самоорганизация.

При первом входе менти один раз проходит ситуационный опросник из 30 вопросов за 10–15 минут. Показать прогресс, дружелюбные подсказки на рубежах и Lottie в конце. Три вопроса на навык дают до 9 баллов. Индекс сектора — сумма по ключу, делённая на 9 и умноженная на 100, с округлением. Это примерная входная оценка. Дальше Макар выставляет оценку 1–5 с датой и основанием, а результат теста сохраняется отдельно. В прототипе оценка ментора от 1 до 5 занимает 20–100% радиуса. Повторного прохождения нет.

**Харды.** Макар сам собирает набор под каждого менти и при необходимости добавляет ещё один фиолетовый круг. В круг помещается до 10 навыков, включая небольшие наборы на 2–3 навыка. Каждый хард стартует с нуля, ментор обновляет уровни сам. При первом достижении хорошего уровня по всем навыкам круга проигрываем Lottie. В прототипе порог 75% на каждый навык.

## Что обсуждаем

- **Навыки.** Подтвердить порог хорошего уровня для хардов. Рабочий вариант для обсуждения — связать навык с задачей и после разбора сохранить основание оценки и ссылку на результат.
- **Календарь.** Разрешение на перенос можно задавать у каждой задачи. Уточнить, нужна ли возможность запросить перенос у ментора и надо ли записывать причины.
- **Фотодневник.** Предлагаем доступ самому менти и его ментору. Согласовать, нужно ли делиться отдельной записью с кем-то ещё.
- **Проекты.** Ссылки на GitHub и Figma относятся к проекту. Счётчики активности в профиль не входят. Список событий для трекинга проекта открыт.

Рабочий сценарий первого запуска: менти входит через Telegram, проходит тест по софтам, получает задачу в календаре, сдаёт работу по ссылке и видит комментарий ментора в профиле. По этому сценарию можно решить, какие данные GitHub и Figma нужны уже в первом запуске.

## Идея для отдельного обсуждения

**Покер без денег.** Рабочий вариант — менти независимо выбирают карточку сложности реальной задачи и коротко объясняют оценку. После выполнения сверяют прогноз с тем, что вышло, и получают жетоны за точность и за замеченные риски. Жетоны можно обменять на право выбрать тему следующего общего разбора или на обложки и стикеры.
